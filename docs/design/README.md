## How to use

- **Decision log:** All architectural decisions are recorded in [DECISIONS.md](DECISIONS.md) using a lightweight ADR format.
- **Design documents:** Larger designs that need diagrams, alternatives analysis, or phased plans get their own file in this folder and are linked from DECISIONS.md.
- **When to add an ADR:** Any change that picks one approach over another, introduces a new dependency, changes the data model, or modifies the public API should get an ADR entry.
